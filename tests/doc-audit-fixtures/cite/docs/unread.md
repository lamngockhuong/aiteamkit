# Settings

The settings come from `.env:1`.
The same file in capitals is `config/.ENV`.
The deploy key is `keys/deploy`.
The dump is `data/dump.sql`.
A link to the settings is `docs/env-link`.
A link out of the repository is `docs/out-link/notes.md`.
A path out of it is `../../outside.md`.
An absolute path is `/etc/hostname:1`.
The certificate is `certs/server.pem`.
The service account is `config/serviceAccountKey.json`.
The deploy secrets are `config/secrets.yml`.
The login file is `.netrc`.
The stored git login is `home/.git-credentials`.
The cloud login is `home/.aws/credentials`.
The cluster login is `home/.kube/config`.
The infrastructure state is `infra/terraform.tfstate`.
The template is `config/.env.example`.
A small dump is `data/small.sql`.
