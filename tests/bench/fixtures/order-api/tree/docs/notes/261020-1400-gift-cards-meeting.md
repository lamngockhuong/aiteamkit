# Meeting note: gift cards, 2026-10-20

Present: Bench PM, Bench Lead, Bench QA, and the client's shop manager.

- The shop wants to sell gift cards and let customers pay with them at checkout, from the next
  release.
- A gift card has a code and a balance in cents. A customer enters the code at checkout and the
  balance pays for the order, or part of it.
- Shop manager: "the gift card comes off the price". Bench Lead asked whether that is before or
  after tax; the shop manager said both have been done at other shops and they would come back on
  it. Nobody decided.
- A gift card can be used with a discount code in the same order.
- What is left on a card after an order stays on the card for the next order.
- Codes "should be hard to guess". Length and characters were not discussed.
- A card expires a year after it is bought.
- Bench QA asked for test cards on the staging shop.
